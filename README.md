# Maç Nerede? · Prototip

Canlı maç yayını yapan mekanları (bar, kafe, kıraathane) harita ve listede bulmayı sağlayan bir ürün fikrinin tıklanabilir prototipi.

**Uygulamayı dene:** https://sarptekinturhan.github.io/mac-nerede-demo/

- Pilot bölgeler: Taksim / Beyoğlu ve Fatih
- İki taraf: izleyici ekranı ve mekan paneli (`panel.html`)
- Tüm mekanlar, maçlar, yorumlar ve fiyatlar **sentetiktir** (uydurmadır). Gerçek işletmeleri temsil etmez.
- Mekan panelinde yapılan değişiklikler yalnızca kendi tarayıcında saklanır.

Bu depo yalnızca uygulamanın yayın kopyasıdır. Ürün yönetimi çalışması (araştırma, kararlar, testler) ayrı tutulmaktadır.
